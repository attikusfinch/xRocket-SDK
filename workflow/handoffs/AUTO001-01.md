# AUTO001-01: контролируемый цикл отдельных сессий

Дата: 2026-10-17. Итог настройки: done; прогресс исполнителей хранится отдельно.

## Результат

Пользователь запросил автоматическое создание/выполнение/контроль сессий, затем
выбрал частоту 5 минут и automatic commit/push после tests + независимого review.
Настроен нативный heartbeat `xrocket-sdk` в этом чате-координаторе, статус ACTIVE.
Его prompt и `workflow/AUTOPILOT.md` задают serial worker → fresh read-only reviewer
→ исправления (до двух кругов) → review journal → commit/push → следующий ID.

Scope зафиксирован: P010–P018, X001. Новые Exchange карточки после X001 не входят
автоматически. P001–P009 и P019 приняты как уже выполненные; их код не менялся.
Координатор использует native create_thread/wait_threads/send_message_to_thread;
дочерние workers не создают собственную цепочку сессий. Модель не переопределяется.

Обновлены workspace/SDK AGENTS, START/README, карточка/очередь, STATE/DECISIONS,
ignore и sdist exclude. Локальный runtime `workflow/.autopilot/state.json` не входит
в Git/архив; там сохраняются automation/thread IDs, scope, dispatch nonce и checkpoints.
ID первого worker и последующие review факты проверяются в runtime и native чатах;
это не новый источник статусов задач вместо tasks.json.

## Продолжение

После сохранения настройки включается runtime и один раз диспетчеризуется P010.
За его завершением и следующими шагами следит heartbeat; координатор не пишет
tracked файлы при активном worker. При неизвестном dispatch не создавать дубликат.
Пауза/остановка пользователя отключают новые шаги и переводят heartbeat PAUSED;
уже работающий worker не прерывается без отдельного запроса. Компьютер и приложение
должны оставаться включёнными для локального исполнения.
