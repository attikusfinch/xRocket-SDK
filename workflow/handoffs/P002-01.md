# P002-01: публичный типизированный health

Дата: 2026-10-17. Итог: done.
Текущий статус — в [tasks.json](../tasks.json).

## Результат и файлы

Добавлены `pay.health.get()` и `await pay.health.get()` через существующий
sync/async transport, `GET /health` без обязательного JWT. Новые
`models/health.py` и `resources/health.py`, wiring в `client.py`; классы `Health`
и `HealthComponent` экспортированы из `xrocket.pay` и `xrocket.pay.models`.
`status` сохраняется строкой, `info`, `error`, `details` — обязательные списки
компонентов с обязательными name/status и необязательным message. Неизвестные
поля сохраняются на обоих уровнях.

В `_core/transport.py` добавлено только точное разрешение `/health`. Прежние
проверки origin, query/fragment, auth isolation, timeout, redirects и lifecycle
сохранены. `tests/test_health.py` проверяет новый ресурс; `test_transport.py`
дополнен отказами до сети для небезопасных и неразрешённых путей обоих transport.
README, architecture и Pay spec описывают реализованное поведение.

При входе Git checkout был чистым, HEAD `ed70137`. Временный `git -c
safe.directory=F:/xrocket-pay/xrocket-sdk` обошёл проверку владельца без изменения
глобальной конфигурации; `core.excludesFile=NUL` использован для read-only diff,
чтобы не читать недоступный пользовательский ignore. Commit/push не выполнялись.
GIT001 и прочие прежние файлы не перезаписывались.

Пользователь после завершения P001 явно разрешил продолжать очередь в текущем
чате до приблизительно 50% контекста. Это исключение для текущего запуска;
постоянное правило одной задачи в AGENTS.md не менялось. Для каждой задачи
сохраняются отдельные handoff, проверки и переход статуса.

## Решения и контракт

См. D013 в [DECISIONS](../DECISIONS.md) и раздел `health.get()` в
[Pay spec](../../spec/pay-api.md). Источник DTO — точная inline schema
`#/paths/~1health/get/responses/200/content/application~1json/schema` локального
Current OAS. Нового upstream override нет; snapshot не редактировался.
Метод соответствует resource API, отдельный HTTP-клиент и retries не добавлены.
Если SDK token задан, применяется прежняя политика публичных методов;
default auth/Authorization внедрённой HTTP-сессии не наследуется.
