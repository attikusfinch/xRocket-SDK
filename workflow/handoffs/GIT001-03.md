## Проверки

- На входе Git working tree чистый, origin URL соответствует заданию пользователя.
- `git ls-remote --symref ... HEAD refs/heads/main` до push: remote пустой.
- `git push --set-upstream origin main`: passed, создана main на GitHub.
- Сравнение `git rev-parse HEAD` / `git ls-remote origin refs/heads/main`: SHA совпали.
- `git status --short --branch`: чисто, main...origin/main.
- После обновления контекста выполняются workflow/diff checks; commit с этим
  итогом отправляется обычным follow-up push и повторно сверяется с remote.
