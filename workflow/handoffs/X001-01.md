## Решения и контракт

[D034/035](../DECISIONS.md) и [spec](../../spec/exchange-api.md) содержат основания.
Официальные EN overview/reference проверены заново. Swagger link найден через
официальную RU reference; UI script содержит swaggerDoc. Raw `/api/docs-json`
проверен HTTP200 и parsed equality с embedded schema; snapshot не исправлялся.
Дата UTC получения 17 октября соответствует локальному 18 октября.

OAS3.0.0 / info1.0.0 / servers[] / 53 schemas; bearer HTTP scheme имеет JWT metadata,
но SDK JWT validation/claims из этого не выводятся. 10 public / 16 bearer operations.
Reference не помечает fees/quotas как private при bearer OAS; /health отсутствует
в reference method table; `kind`/required info/examples не полностью согласованы.
openTime plain string не превращается в datetime по примеру; positional arrays
не получают неподтверждённые fixed length guarantees. Эти ограничения открыты.

Для X002 менять core не требуется: `/api/` GET, exact200 adapter, problem retention,
pooling/ownership и independent auth уже поддержаны. DTO/Decimal/aliases, dynamic
path safety и будущая numbered pagination остаются Exchange. Pay credentials,
sessions, models/cursor не объединяются; WS lifecycle не входит в HTTP transport.
Client IDs не доказывают safe replay; retries и финансовые запросы не добавлены.
