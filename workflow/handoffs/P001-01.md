# P001-01: Pay-модели по ресурсам с сохранением импортов

Дата: 2026-10-17. Итог: done.
Это итог сессии; текущий статус задачи хранится в [tasks.json](../tasks.json).

## Результат и файлы

Выполнена только P001. Вместо `src/xrocket/pay/models.py` создан пакет
`src/xrocket/pay/models/` из семи файлов:

- `__init__.py`: явные re-exports и `__all__` для 13 прежних классов и `Money`.
- `_base.py`: прежние `_ResponseModel`, `_decimal` и `Money` без изменений.
- `app.py`, `currencies.py`, `rates.py`, `invoices.py`: DTO существующих ресурсов.
- `pagination.py`: Pay `CursorPagination` / `CursorPage` и их TypeVar.

Импорты 13 классов из `xrocket.pay` и `xrocket.pay.models` возвращают одни и те же
объекты; `Money` остаётся доступен из `xrocket.pay.models`. `pay/__init__.py`,
клиенты, ресурсы, `_core`, Exchange и OAS не изменены. Новых endpoints нет:
по-прежнему реализованы шесть Current Pay GET-операций с sync/async симметрией.

В `tests/test_models.py` добавлены 13 проверок идентичности публичных импортов
и проверка прежнего импорта `Money` с точным Decimal. В `spec/architecture.md`
отражены фактические файлы и зависимости. Обновлены STATE, DECISIONS (D011)
и статус/ссылка в очереди.

Git не инициализирован, commit/diff отсутствуют. До изменения runtime сохранён
временный снимок исходного models.py, AST и SHA-256 существующих файлов; сравнение
подтвердило, что из прежних runtime-файлов изменён только удалённый models.py.
Незавершённых `in_progress` на входе не было. Исходные BASE/FLOW файлы приняты
как существующая база и не перезаписывались.

## Решения и контракт

См. [D011](../DECISIONS.md) и [архитектуру](../../spec/architecture.md).
Общие response config/Money и pagination остаются внутри Pay; новые пустые модули
или общая абстракция для Exchange не добавлялись. Ресурсы продолжают импортировать
модели через прежний `xrocket.pay.models`.

Сохранены поля, порядок, defaults, aliases, Decimal validation, aware datetime,
неизвестные поля/statuses и generic page. Имена модулей определений классов теперь
соответствуют их размещению; гарантии формата pickle для generic models не
добавлялись. Новых неизвестных деталей upstream нет: это локальный перенос,
сеть и изменение API-контракта не требовались.
