## Решения и контракт

См. [D029](../DECISIONS.md), [Pay contract](../../spec/pay-api.md),
карточку [P015](../tasks/P015.md) и handoff зависимости [P008](P008-01.md).
Использованы только нужные фрагменты сохранённого Current OAS; сеть не нужна.

- Request требует network (`TON`, `BSC`, `ETH`, `BTC`, `TRX`, `SOL`), address/max100,
  asset и finite Decimal/decimal string amount. Сумма уходит точной JSON string,
  без float, округления/обрезки scale и придуманных денежных bounds.
- Network задаётся явно несмотря на OAS property default TON. Optional comment
  max50 и platform string пропускаются при omission; explicit None запрещён,
  поскольку nullable отсутствует. Platform передаётся только вызывающим кодом,
  по описанию — если предоставлен xRocket. Length/enum platform не выдуманы.
- Пустота строк не запрещена OAS minLength; blockchain/asset/Unicode строки не
  нормализуются. Локальная schema acceptance не доказывает server acceptance.
- Response `telegram_bot_link`, `telegram_mini_app_link`, `web_link` независимо
  optional, даже `{}` допустим по отсутствию required. Missing → None; present
  field должен быть строкой, explicit null отвергается по сохранённому OAS.
  Live nullable override не вводился. Для omission roundtrip — exclude_unset.
  URL/host/scheme/непустота/at-least-one guards не добавлены; unknown fields и
  исходные строки сохраняются. Полученные ссылки не открываются.
- Request/response отделены от прямого withdrawal: нет client ID, callback,
  автоматического quotas/lookup. Legacy GET не реализуется этим ресурсом.
- Документированные 400/401/404/429/500 problems сохраняют прежнюю classification
  и metadata. Устаревшая 401 description «Unknown API Key» не меняет bearer
  security; это оговорено в spec, snapshot не исправлялся.
- Одна HTTP попытка, без retries/redirects/polling/переходов по links. Timeout
  оставляет создание неизвестным; idempotency, safe replay, expiry и фактическая
  доступность/форма ссылок не установлены. Link не доказывает завершение withdrawal.
