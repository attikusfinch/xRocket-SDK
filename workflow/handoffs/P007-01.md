# P007-01: Opt-in read-only testnet harness и журнал подтверждений

Дата: 2026-10-17. Итог: done (harness и журнал).
Текущий статус — в [tasks.json](../tasks.json).
Live health остаётся failure; отдельное исправление — P019.

## Результат и файлы

Добавлен harness для всех 15 Pay GET: 40 cases (sync/async), 6 public и 34 private.
Расширен `tests/integration/test_public_live.py` (health и оба клиента), добавлены
`test_private_live.py` и общий `conftest.py`. В `pyproject.toml` уточнено описание
marker live; default `-m 'not live'` сохранён.

Public читает currencies/rates/health без JWT. Private app/balances и четыре lists
независимы от IDs; retrieve/payment cases используют только явный server/client ID
по отдельности, quotas — отдельную явную network/asset pair. Без opt-in запросов
нет. При opt-in отсутствие JWT/конкретного fixture даёт понятный независимый skip;
ошибки сети/HTTP/schema/неверного fixture остаются failures. Private setup/GET/cleanup
failures без traceback с record/ID/token/problem details; request logs отключаются
на время test и восстанавливаются. Ответы аккаунта не записываются.

`tests/test_live_harness.py` запускает реальный harness в отдельных pytest
processes с fake env и подставленным HTTPX send: 8 offline сценариев проверяют
default deselection, opt-out, no-JWT, no-IDs, full/partial fixtures, private failure
и unavailable public testnet. Проверяются fixed testnet GET, изоляция public/private
token, 15 paths, independent counts и отсутствие synthetic secrets/records в stdout.

Добавлен [журнал live](../../spec/live-verification.md), обновлены README,
`spec/test-plan.md`, `spec/pay-api.md` (PAY-018), STATE, DECISIONS (D018), очередь.
Новая карточка [P019](../tasks/P019.md) поставлена после P007 перед P008;
финальная P018 теперь зависит от её завершения. IDs существующих задач не менялись,
operations остаются распределены ровно один раз (P019 — fix, operations пусты).

При входе оставались P004–P006 working changes; они сохранены. Все runtime .py,
исторический `spec/verification.md` и предыдущие handoffs совпадают byte-for-byte
с baseline `.tmp/p007-baseline/`. SDK runtime, snapshots, exports и dependencies
не менялись. Commit/push не выполнялись. Git command-local safe.directory сохранён;
предупреждение о недоступном пользовательском ignore не блокирует status/diff.

## Решения и контракт

См. [D018](../DECISIONS.md), [план запусков](../../spec/test-plan.md).
Единственный token source — `XROCKET_PAY_TESTNET_TOKEN`, только private клиент.
Environment жёстко testnet, timeout 15, base URL override не добавлен. Все операции
GET, IDs не угадываются/не берутся из lists; личные env значения не параметризуют
имена tests. Чувствительные значения не выводились при проверке env availability.

Точная матрица fixture variables и skips — в test-plan. При наличии JWT, но без
IDs, public + independent app/list дают 18 cases, остальные 22 skips. Полный fake
набор даёт 40 offline mock passes. Это подтверждение harness, не живого API.

Новый факт live: public currencies/rates проходят в обоих клиентах; health нет.
Дополнительный публичный GET 2026-10-17 16:28:55 UTC вернул HTTP 200 и единственный
JSON field status=`ok`. OAS требует status/info/error/details, и P002 decoder
даёт ResponseValidationError. Это PAY-018; P007 не расширена исправлением
runtime, а сохранила failure и завела P019. Её критерии: поддержать минимальный
и полный health shapes, явно определить missing-components policy, regression tests.

Private JWT/IDs/quota fixtures отсутствовали. 34 skips не подтверждают nullable
overrides, реальные records, quotas или PAY-016/017. Mainnet, mutations, реальные
платежи, webhooks, Legacy и Exchange не выполнялись. Исторические результаты BASE
не переписаны и не выданы за текущие private/live успехи.
