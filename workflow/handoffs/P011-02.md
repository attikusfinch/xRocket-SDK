Исправлен источник ошибки в `src/xrocket/_core/serialization.py`:
recursive request graph guard проверяет str на U+D800–U+DFFF, включая dict keys.
Строки проверяются до revalidation и после нормализации/field serialization;
финальная проверка видит password, намеренно раскрытый для wire.
Невалидный Unicode отвергается общим ValueError до создания JSON text и I/O.
UnicodeEncodeError не создаётся и не перехватывается; исключение не сохраняет
clear JSON в object/args или скрытой cause/context цепочке.

  нормальный Unicode/astral password/description/payload сохраняют UTF-8 bytes.
- 13 в `tests/test_request_serialization.py`: все четыре surrogate границы,

## Решения и контракт

См. [D025](../DECISIONS.md), [Pay contract](../../spec/pay-api.md),
[architecture](../../spec/architecture.md). Surrogate code points не являются
Unicode scalar values: SDK отвергает их, включая явно записанную пару Python
surrogate code units. Настоящие astral characters (один Unicode scalar), CJK,
кириллица, emoji и combining characters передаются без нормализации/замены.
Это локальная encoding policy; новый API constraint/override не выдумывается,
OpenAPI snapshot не менялся.

Исправление превентивное: нет catch с `from None`, который оставлял бы опасное
UnicodeEncodeError в доступном `__context__`. Bare ValueError содержит только
общую причину; нормальный wire JSON по-прежнему содержит намеренно переданный
password. Явный raw body/get_secret_value/raw server problem остаются доступными
данными, их не следует журналировать. Границы внешнего Pydantic malformed-JSON
парсинга из прежнего handoff сохраняются; это не путь отправки готового SDK DTO.
