# Промпты сессий

Открывай корень SDK. Для каждого промпта действуют `AGENTS.md`, `workflow/STATE.md` и
одна карточка. Список задач/статусов не копируем в промпты — он в `tasks.json`.

## Следующая задача

```text
Прочитай AGENTS.md и START.md проекта xrocket-sdk.
Выполни следующую доступную задачу из workflow/tasks.json.
При наличии in_progress продолжи её после чтения handoff и проверки файлов.
Одна задача за сессию. Закончи реализацию, необходимые проверки и handoff,
обнови очередь/контекст и остановись, не начиная следующую карточку.
```

## Конкретная задача

```text
Прочитай AGENTS.md, workflow/STATE.md и workflow/DECISIONS.md.
Выполни только задачу P001 из workflow/tasks.json по её карточке.
Проверь зависимости, фактические файлы и handoffs зависимостей.
Доведи задачу до её критериев готовности, сохрани новый handoff и обнови
очередь/контекст. Если зависимость не выполнена, не обходи её и не начинай другую задачу.
```

Заменяй `P001` нужным ID. Точный промпт с путями печатает `tools/session.py prompt ID`.

## Продолжить незавершённую задачу

```text
Продолжи текущую in_progress задачу xrocket-sdk по AGENTS.md.
Прочитай её карточку и последний handoff, затем проверь реальные изменения.
Если сессия оборвалась без handoff, восстанови состояние из файлов и проверок.
Не начинай заново уже выполненную часть и не считай её проверенной без evidence.
Закончи только этот ID, запиши новый handoff с увеличенным номером и обнови очередь.
```

## Отдельная проверка результата

```text
Сделай read-only review задачи P001 в xrocket-sdk.
Прочитай AGENTS.md, карточку, последний handoff, связанные specs, код и tests.
Проверь выполнение acceptance, соответствие контракту, sync/async и регрессии.
Укажи только конкретные дефекты с местом/сценарием и приоритетом.
Не исправляй код, не меняй очередь и не начинай следующую задачу.
Если находок нет, так и скажи; перечисли существенные непроверенные области.
```

## Создать новую задачу из идеи

```text
Добавь в очередь xrocket-sdk задачу: <желаемый результат>.
Сначала прочитай AGENTS.md, workflow/STATE.md, workflow/tasks.json и нужные specs/source.
Создай карточку по workflow/templates/task.md с новым стабильным ID,
зависимостями, ограниченным scope и критериями готовности на одну сессию.
Добавь её в tasks.json, проверь очередь. Сейчас не реализуй задачу.
```

## Сохранить контекст перед ручным завершением

```text
Сохрани передачу текущей задачи перед завершением сессии.
Запиши новый workflow/handoffs/<ID>-<NN>.md по template: что готово, что проверено,
что осталось, решения и конкретный следующий шаг. Обнови handoff/status в tasks.json
и краткий STATE.md. Незавершённую работу не отмечай done. Другую задачу не начинай.
```
