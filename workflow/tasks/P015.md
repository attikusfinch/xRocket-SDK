# P015: Создание withdrawal link

## Цель
Добавить отдельный withdrawal_links resource без смешения с прямым withdrawal.

## Прочитать
- `AGENTS.md` — общий протокол одной сессии; статусы берутся из `workflow/tasks.json`.
- `spec/pay-api.md`: inventory №21 и отличие Current POST от Legacy GET.
- Актуальные Pay client и request serialization после P008.
- WithdrawalLinkRequestDto и WithdrawalLinkResponseDto.

## Входит
- POST /api/v1/withdrawal-link: network, address, asset, amount, comment/platform.
- Типизированные необязательные telegram/web links.
- Одинаковое подключение ресурса к PayClient и AsyncPayClient.

## Не входит
- GET Legacy, открытие полученной ссылки, прямой вывод средств, live POST.

## Приёмка
- Wire verb POST, точный singular /withdrawal-link; сумма строкой.
- Request constraints взяты из DTO; ссылки не становятся required без основания.
- Отсутствие одного из links не ломает decode; неизвестные response fields допустимы.
- Method/body/errors одинаково работают в sync и async.

## Проверка
- Создать `tests/test_withdrawal_links.py`.
- После создания: `.venv\Scripts\python.exe -m pytest tests/test_withdrawal_links.py`.
- Тестировать только MockTransport; создание live link требует отдельной инструкции.

## Источники
- `#/paths/~1api~1v1~1withdrawal-link/post`.
- `WithdrawalLinkRequestDto`, `WithdrawalLinkResponseDto`.
