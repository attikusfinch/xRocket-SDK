# X002: Первый public Exchange REST срез — symbols

Статус и зависимости — только в [очереди](../tasks.json). Новая карточка вне
сохранённого scope запуска `ap-48ca458fcbf2`; её создание не разрешает исполнение.

## Результат

`ExchangeClient` и `AsyncExchangeClient` читают список и один symbol через
`symbols.list()` / `symbols.retrieve(symbol=...)`. Это один ограниченный срез;
planned ownership двух операций не означает наличие методов до выполнения карточки.

## Сделать

- Создать отдельные Exchange clients, resource и response DTO. Выбрать только
  подтверждённые в spec origins; Exchange credentials и session ownership независимы
  от Pay. Public symbols доступны без token; не добавлять обязательную авторизацию.
- Обе операции успешны только при HTTP 200; прочие 2xx — ошибка контракта.
  Существующий core позволяет явный `success_statuses=(200,)`: новое обобщение
  transport не нужно без конкретного доказанного ограничения.
- `SymbolsResponse.symbols` — список `SymbolResponse`; monetary size/price/increment
  strings и `precisions` читать через собственный Exchange Decimal type. Python fields
  — snake_case, wire aliases — camelCase; неизвестные response fields/labels сохранять.
- `openTime` не входит в required и объявлен plain string, без `format` и `nullable`.
  Сохранить omission и строковое значение; не вводить datetime/null override по примеру.
- До I/O гарантировать один безопасный path segment для symbol: описать SDK policy
  проверки/encoding отдельно от бизнес-ограничений OAS. Проверить пустую строку,
  dot segments, `/`, `\\`, `?`, `#`, `%`, Unicode и invalid surrogate; input не должен
  менять endpoint, origin или query. Не выводить regex допустимых symbols из примера.
- Сохранить problem details целиком, включая неизвестные поля; проверить документированные
  400 symbol unavailable, 404 symbol not found, 500, а также non-JSON failure.
  Не обещать retries, pagination или частные методы.

## Вне scope

Assets/ticker/candles/orderbook/trades/rates/health, private account/orders/funding,
WebSocket, объединение DTO или HTTP sessions с Pay, live запросы с секретами.

## Готово, когда

- Sync/async имеют одинаковые imports, lifecycle и результаты; list делает один GET,
  retrieve безопасно передаёт ровно один symbol. Закрытие owned/external sessions,
  timeout, redirects, отсутствие retries и token isolation проверены offline.
- Targeted `tests/test_exchange_symbols.py` покрывает обе wire формы, exact 200,
  Decimal precision, aliases, unknown fields/labels, missing/present `openTime`,
  безопасные ошибки и проверку path до transport I/O.
- Выполнены targeted tests, полный offline pytest, Ruff, strict mypy и build
  (появляются public exports), а также workflow/link checks по `AGENTS.md`.
- Примеры используют public market data без secrets; spec, imports, handoff и очередь
  отражают именно эти две реализованные операции. Pay coverage остаётся 25/25.
