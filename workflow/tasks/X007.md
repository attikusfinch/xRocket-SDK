# X007: Public Exchange recent trades

Статус и зависимости — только в [очереди](../tasks.json). Карточка вне сохранённого
scope `ap-48ca458fcbf2`; одна planned operation не означает private trade history.

## Результат

Sync/async чтение GET `/api/v1/trades` по обязательному query `symbol`.

## Прочитать

- `AGENTS.md`, [контракт Exchange](../../spec/exchange-api.md), [X002](X002.md)
  и handoff X002 из [очереди](../tasks.json).
- Exchange OAS только trades path, `TradesResponse`, `TradeResponse` и ошибки;
  фактические Exchange query/response models и tests после X002.

## Сделать

- Читать envelope `trades`; required item fields: `tradeId`, `price`, `side`,
  `time`, `size`. ID/time остаются строками, price/size — Decimal, aliases snake_case.
  `side` документирует buy/sell; неизвестное response значение/поля сохраняются.
- Public tokenless один запрос с exact 200. Snapshot не предоставляет limit/cursor
  или документированного server default count: не добавлять pagination/limit.
- Сохранить documented failure shapes; проверить фактические status codes path,
  не копировать контракт order history.

## Вне scope

Private account trades, order history, WS trades, auto-pagination и pooling с Pay.

## Готово, когда

- `tests/test_exchange_trades.py` проверяет sync/async wire symbol, empty trades,
  Decimal precision, string IDs/time, unknown side/fields, exact 200 и failures.
- Общие code/export checks `AGENTS.md`, workflow/link checks, spec и handoff выполнены;
  operation не дублируется в Orders или WebSocket coverage.
