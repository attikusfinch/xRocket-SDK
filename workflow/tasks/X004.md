# X004: Public Exchange 24h ticker

Статус и зависимости — только в [очереди](../tasks.json). Карточка вне сохранённого
scope `ap-48ca458fcbf2`; одна planned operation ещё не является public методом.

## Результат

Одинаковый sync/async read resource для GET `/api/v1/ticker/{tickerType}`.

## Прочитать

- `AGENTS.md`, [контракт Exchange](../../spec/exchange-api.md), [X002](X002.md)
  и фактический handoff X002 из [очереди](../tasks.json).
- Только ticker path/params, `TickersResponse` / `TickerResponse` и ошибки Exchange
  OAS; существующие Exchange client/DTO/query helpers и tests после X002.

## Сделать

- Request `tickerType` имеет единственное доказанное значение `24h`; query `symbols`
  необязателен, array of strings; omission означает все symbols. Зафиксировать
  array query serialization по OAS/defaults и проверить точный wire.
- Читать envelope `tickers`. `startTime`/`endTime` — required plain strings;
  open/close/high/low/changeRate/changePrice/baseVolume/quoteVolume/last — numeric
  strings, читаемые как Decimal; `symbol` — строка. Не выводить datetime format
  из примеров и не вводить другие ticker periods без источника.
- Public tokenless GET, exact HTTP 200, aliases и unknown response fields сохранить;
  failures 400/404/500 должны сохранять problem details.

## Вне scope

WebSocket ticker, периодические polling/retry loops, candles, aggregation и pagination.

- Выполнены общие code/export checks `AGENTS.md`, workflow/link checks; spec/example,
  handoff и единственное operation ownership согласованы.
