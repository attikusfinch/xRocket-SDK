# GIT001: Подключить GitHub и исключить локальные файлы

Статус/зависимости — в `workflow/tasks.json`. Задание пользователя: подключить
`https://github.com/attikusfinch/xRocket-SDK.git` после завершения P001.

## Результат

Git root в папке SDK, remote origin указывает на предоставленный репозиторий;
исходный проект с результатом P001 сохранён в Git без локальных артефактов.

## Прочитать

- AGENTS.md, START.md, workflow/STATE.md и handoff P001.
- .gitignore, pyproject.toml и фактический список файлов.

## Входит

- Проверить remote и существующую историю до Git mutations.
- Дополнить Python/Windows/editor/secrets ignores, проверить исключения шаблонов.
- Инициализировать Git, настроить origin и main, сохранить первый коммит и push.
- Обновить текущие сведения о Git и инструкции клонирования.

## Вне scope

P002, изменения runtime SDK, CI, публикация PyPI и переписывание remote истории.

## Приёмка

- Исходники, tests, specs/OAS, lock, карточки и handoffs включены.
- .venv, кэши, dist/build, .env и ключи не включены; .env.example разрешён.
- Workflow check и diff check проходят; локальная main отслеживает origin/main.
- Первый коммит доступен на GitHub, working tree чистый.
