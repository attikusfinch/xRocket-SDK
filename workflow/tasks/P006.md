# P006: Чтение withdrawals и квот

## Цель
Добавить согласованный read-only ресурс withdrawals с проверкой комиссий и лимитов.

## Прочитать
- `AGENTS.md` — общий протокол одной сессии; статусы берутся из `workflow/tasks.json`.
- `spec/pay-api.md`: inventory №18–20, PAY-012, PAY-016 и PAY-017.
- Актуальные Pay client/resources/models после P001; точные query schemas snapshot.
- WithdrawalResponseDto, WithdrawalListResponseDto, WithdrawalQuotasResponseDto.

## Входит
- GET /api/v1/withdrawals: fromDate/toDate, status, cursor, limit.
- GET /api/v1/withdrawal: withdrawalId/clientWithdrawalId.
- GET /api/v1/withdrawal-quotas: обязательные network и asset.

## Не входит
- Создание withdrawal/link, догадки о missing-ID ответе или серверной дедупликации.

## Приёмка
- Uppercase known statuses сохраняются буквально; неизвестные значения допустимы.
- withdrawMinSize/withdrawFee — Decimal, precision — числовая точность, не деньги.
- Разницу длины clientWithdrawalId create/retrieve нельзя скрывать общим maxLength.
- PAY-017 отражён как неподтверждённая семантика; SDK policy не выдаётся за факт сервера.

## Проверка
- Создать `tests/test_withdrawals_read.py`, включая required quotas query.
- После создания: `.venv\Scripts\python.exe -m pytest tests/test_withdrawals_read.py`.
- Проверить minimal/optional DTO, точность денег, страницы и обе версии клиента.

## Источники
- `#/paths/~1api~1v1~1withdrawals/get`, `#/paths/~1api~1v1~1withdrawal/get`.
- `#/paths/~1api~1v1~1withdrawal-quotas/get`; PAY-016/017.
