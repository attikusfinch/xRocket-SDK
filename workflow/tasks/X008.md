# X008: Public Exchange fiat rates

Статус и зависимости — только в [очереди](../tasks.json). Карточка вне сохранённого
scope `ap-48ca458fcbf2`; ownership — planned coverage одной REST операции.

## Результат

Sync/async GET `/api/v1/rates` со своей map response, независимо от Pay rates.

## Прочитать

- `AGENTS.md`, [контракт Exchange](../../spec/exchange-api.md), [X002](X002.md)
  и handoff X002 из [очереди](../tasks.json).
- Exchange OAS rates path и `AssetRateResponse`; Exchange query/Decimal/response
  helpers после X002, без импорта Pay Rate или pagination.

## Сделать

- Required query `base` — string; optional `assets` и `intervals` — arrays.
  Intervals: `1h`, `24h`, `7d`, `30d`, `90d`, `365d`. Wire serialization arrays
  подтвердить OAS/defaults и тестом. Не придумывать enum fiat currencies из USD example.
- Response — top-level mapping asset code → `AssetRateResponse`, без envelope.
  `rate` и `rateChangePercent24h` обязательны; поля изменений 1h/7d/30d/90d/365d
  optional. Numeric strings — Decimal; missing optional value не становится нулём.
- Неизвестные keys/response fields сохранять; exact 200 и documented failures.
  Query intervals description обещает 24h всегда; отразить это как контракт OAS,
  не превращать отсутствие дополнительных интервалов в неявный повтор запроса.

## Вне scope

Pay rates, conversion engine, кэш, background polling, retries и WS.
