# P009: Invoice create и delete

## Цель
Добавить создание и удаление invoice поверх готового write pipeline.

## Прочитать
- `AGENTS.md` — общий протокол одной сессии; статусы берутся из `workflow/tasks.json`.
- `spec/pay-api.md`: invoice create, PAY-008/012/014, expiresIn и clientInvoiceId.
- Текущие invoice resources/models и request serialization после P008.
- InvoiceCreateRequestDto и обе operation schemas сохранённого snapshot.

## Входит
- POST /api/v1/invoices с отдельным request type и типизированным Invoice response.
- DELETE /api/v1/invoice с invoiceId/clientInvoiceId и bodyless success.
- Отразить request fields/aliases и условие priceAmount/minPayment в контракте.

## Не входит
- Payment address, другие ресурсы, создание invoice в живом аккаунте, retries.

## Приёмка
- Суммы сериализуются строками без округления; expiresIn сохраняет миллисекунды и 0.
- Конфликт prose/OAS по open amount не скрыт произвольной безусловной обязательностью суммы.
- Client validation и её основания явно описаны; unresolved upstream facts остаются в ledger.
- DELETE принимает пустой 200; IDs и необязательные поля не меняют wire semantics.

## Проверка
- Создать `tests/test_invoices_write.py` с sync/async create/delete контрактами.
- После создания: `.venv\Scripts\python.exe -m pytest tests/test_invoices_write.py tests/test_contracts.py`.
- Live mutations допустимы только по отдельной явной инструкции пользователя.
