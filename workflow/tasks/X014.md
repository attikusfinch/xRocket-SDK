# X014: Contract gate Exchange WebSocket lifecycle

Статус и зависимости — только в [очереди](../tasks.json). Карточка вне сохранённого
scope `ap-48ca458fcbf2`; REST `operations: []`: WS не дублирует REST coverage.

## Результат

Проверенный lifecycle spec и малые future cards для отдельного WebSocket client;
в этой сессии нет socket connection или stream implementation.

## Сделать

- Перепроверить documented environments, connection/auth handshake, envelopes,
  subscription/unsubscription, request IDs/acks/errors и ограничения topics.
  Отдельно разобрать public и private stream boundaries без общих Pay sessions/tokens.
- Уточнить ping/pong contract и missing-pong behavior, disconnect codes/timeouts,
  reconnect/backoff/resubscription, duplicate/out-of-order events и backpressure.
  Отсутствующие server guarantees сохранить как вопросы; client policy пометить
  проектным решением и не выдавать её за API факт.
- Для orderbook выяснить snapshot/delta semantics, sequence/gap detection и resync:
  REST sequence не доказывает автоматически совместимый WS cursor. При отсутствии
  доказательств не планировать гарантированно непрерывную локальную книгу.
- Разбить последующую реализацию на обозримые cards: lifecycle, конкретные public
  topics, затем самостоятельный private contract/implementation scope. Зависимости
  от REST snapshot добавлять только при подтверждённом протоколе.

## Вне scope

WebSocket SDK code, socket/live subscriptions, private auth/секреты, trading/funding,
REST operation ownership, background automation и общие HTTP retries.

## Готово, когда

- Lifecycle матрица содержит source URL/date, подтверждения, противоречия и вопросы;
  missing pong/reconnect/orderbook gaps имеют определённые следующие шаги.
- Созданы малые future cards с mock protocol tests и явными правилами shutdown,
  cancellation/session ownership; ни одна не утверждает неизвестные delivery guarantees.
- Проверены provenance/ссылки и связность очереди через `tools/session.py check`,
  создан новый handoff по `AGENTS.md`; runtime и REST registry не менялись ради WS.
