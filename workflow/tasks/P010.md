# P010: Создание payment address для invoice

## Цель
Добавить один метод создания адреса оплаты с отличающимся success status.

## Прочитать
- `AGENTS.md` — общий протокол одной сессии; статусы берутся из `workflow/tasks.json`.
- `spec/pay-api.md`: inventory №25, identifiers и money/date-time правила.
- Актуальные invoice resource/request types, P003 payments и P008 write pipeline.
- InvoiceCreatePaymentAddressRequestDto и InvoicePaymentAddressResponseDto.

## Входит
- POST /api/v1/invoices/payments/address: invoiceId/clientInvoiceId в query.
- JSON body с обязательным payNetwork; response address/payCurrency/payNetwork/expiresAt.
- Зафиксировать Python имя в стиле существующего invoice resource.

## Не входит
- Платёж на адрес, автооплата invoice, смена остальных write methods.

## Приёмка
- Успех 201 декодируется корректно; этот endpoint не копирует 200-only ожидание.
- Query identifiers остаются в query, payNetwork находится в body.
- minAmount при наличии — Decimal; expiresAt соответствует реальному типу/known overrides.
- Sync/async contracts совпадают, HTTP/API failures доступны через общий error pipeline.

## Проверка
- Создать `tests/test_invoice_payment_addresses.py`.
- После создания: `.venv\Scripts\python.exe -m pytest tests/test_invoice_payment_addresses.py`.
- Все запросы через MockTransport; live address creation отдельно не запускать.
