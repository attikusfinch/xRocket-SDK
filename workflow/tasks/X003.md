# X003: Public Exchange assets

Статус и зависимости — только в [очереди](../tasks.json). Карточка вне сохранённого
scope `ap-48ca458fcbf2`; ownership ниже — план, не реализованные методы.

## Результат

Sync/async Exchange resource читает GET `/api/v1/assets` и GET `/api/v1/assets/{asset}`.

## Прочитать

- `AGENTS.md`, [контракт Exchange](../../spec/exchange-api.md), [X002](X002.md).
- Открыть фактический handoff прямой зависимости X002 по полю `handoff`
  [очереди](../tasks.json); при продолжении — последний собственный.
- В Exchange OAS только эти два paths, `AssetsResponse`, `AssetResponse` и ошибки;
  фактические Exchange client/base/resource и tests после X002.

## Сделать

- Добавить собственные DTO и два read-метода в обе версии клиента. List возвращает
  envelope `assets`; required поля item: `asset`, `precision`, `availableTransfers`.
  `precision` в OAS number: не заменять тип молча на int без обоснования в spec.
- `availableTransfers` документирует `fundingToTrading` / `tradingToFunding`;
  сохранять неизвестные response values/fields. Это сведения о возможностях актива,
  не разрешение выполнять transfers.
- Сохранить безопасный path segment asset по policy X002, отсутствие обязательного
  token и exact HTTP 200. Для retrieve сохранить 404 `/api/problems/asset_not_found`.

## Вне scope

Funding DTO/operations, transfer execution, Pay currencies, auto-pagination и live secrets.

## Готово, когда

- Targeted `tests/test_exchange_assets.py` проверяет sync/async request paths,
  list/envelope, retrieve, unknown fields/directions, numeric precision, unsafe path
  до I/O, exact 200 и 404/500 problem details.
- Общие code/export checks по `AGENTS.md`, workflow/link checks, документация и новый
  handoff выполнены; обе операции сохраняют единственного owner в Exchange manifest.
