# AUTO001: Включить контролируемый цикл разработки

Статус и зависимости — в `workflow/tasks.json`.

## Результат

Координатор в текущем чате сам создаёт отдельные сессии исполнения/review,
проверяет результат и запускает следующую карточку после принятия текущей.

## Авторизация пользователя

Разрешены автоматическое создание и управление рабочими сессиями; выбраны проверки
каждые 5 минут и commit/push изменений после tests и независимого review.

## Входит

- Обновить инструкции ролей и создать устойчивый протокол/локальное состояние.
- Зафиксировать оставшийся scope P010–P018 и X001, сохранить выполненные P001–P009/P019.
- Настроить heartbeat текущего координатора и запустить отдельный worker P010.
- Исключить runtime из Git и исходных архивов; сохранять handoffs/review evidence.

## Вне scope

Реализация самой P010 здесь, concurrent writers, обход approvals, live деньги,
PyPI/deploy и бесконечное добавление работ после X001.

## Приёмка

- Один writer, отдельный reviewer, candidate SHA и review gate перед next/push.
- Результат неизвестного dispatch не создаёт слепой дубликат.
- Нативный heartbeat существует с выбранным ритмом; первый worker создан один раз.
- Workflow/link/build checks пройдены; runtime не отслеживается и не упакован.
