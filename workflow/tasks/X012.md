# X012: Contract gate private Exchange Funding

Статус и зависимости — только в [очереди](../tasks.json). Карточка вне сохранённого
scope `ap-48ca458fcbf2`; пять planned operations ещё не означают funding API SDK.

## Результат

Уточнённый funding spec и малые будущие cards с отдельной границей withdrawal writes.

## Прочитать

- `AGENTS.md`, [контракт Exchange](../../spec/exchange-api.md), [X002](X002.md)
  и handoff X002 из [очереди](../tasks.json); official auth/funding docs из provenance.
- Только GET `/api/v1/accounts/funding/balances`,
  GET `/api/v1/accounts/funding/withdrawal-quotas`,
  POST/GET `/api/v1/accounts/funding/withdrawals`,
  GET `/api/v1/accounts/funding/withdrawal`, их schemas/errors Exchange OAS.

## Сделать

- Разрешить либо явно сохранить auth discrepancy withdrawal quotas между официальными
  источниками; bearer в OAS сам по себе не доказывает permission scope/схему
  генерации credentials. Описать блокирующие зависимости, не запрашивать secrets.
- Зафиксировать отдельные Funding balance/quota DTO; quota required query network/asset,
  current network enum и Decimal numeric strings. Не переносить Pay withdrawal models.
- Withdrawal create: required clientWithdrawalId (1–50), network/asset/address/amount,
  optional comment; success 201. Проверить описание защиты от double spends и duplicate
  error, отдельно отметить неизвестные replay/window/timeout guarantees; retries не обещать.
- Get: withdrawalId (1–20) или clientWithdrawalId (1–50), при обоих wins withdrawalId.
  List: assets/date filters и numbered pagination; explicit Exchange API withdrawals only.
  Response statuses, optional txHash/txLink, string timestamps и mislabelled problem `type`
  зафиксировать по OAS, без ручного исправления snapshot.
- Создать малые future cards для reads и write со своими DoD/offline tests. Перенести
  все пять operations новым owners без дублей; завершённый gate не дублирует manifest.

## Вне scope

Funding SDK implementation, live balance/quota/withdrawal requests, денежные действия,
секреты, подмена старых snapshots и общее Pay/Exchange pagination API.

## Готово, когда

- Контрактные вопросы и auth provenance проверяемы; будущий write scope отдельно
  ограничивает ambiguous timeout и не принимает duplicate error за success.
- Implementation cards имеют dependencies и конкретный mock-only DoD;
  ownership остаётся единственным для всех пяти operations.
- JSON/provenance/link checks, `tools/session.py check`, новый handoff по `AGENTS.md`
  выполнены; ограничения не выданы за live доказательства.
