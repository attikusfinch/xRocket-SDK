# X005: Public Exchange candles

Статус и зависимости — только в [очереди](../tasks.json). Карточка вне сохранённого
scope `ap-48ca458fcbf2`; ownership означает будущий контрактный результат.

## Результат

Sync/async один GET `/api/v1/candles` для явно заданного диапазона времени.

## Прочитать

- `AGENTS.md`, [контракт Exchange](../../spec/exchange-api.md), [X002](X002.md)
  и handoff прямой зависимости X002 по [очереди](../tasks.json).
- В Exchange OAS candles path, `CandlesResponse`,
  `ExchangeTooBigIntervalValidationExceptionDto`; фактические Exchange DTO/query helpers.

## Сделать

- Required query: `symbol`, `type`, `startAt`, `endAt`. Допустимые request periods:
  `1min`, `5min`, `15min`, `30min`, `1hour`, `2hour`, `4hour`, `8hour`, `12hour`,
  `1day`, `1week`, `1month`. Времена — plain strings OAS, без навязанного format.
- Описать безопасный DTO для `candles`: OAS задаёт array of array of strings,
  а prose перечисляет start/open/close/high/low/base volume. Сначала решить и записать
  различие типизированной tuple и сохранения raw строк; не объявлять длину шесть
  серверной гарантией, поскольку minItems/maxItems в snapshot отсутствуют.
  Monetary значения должны оставаться точными, без float.
- Exact 200; сохранить 400 validation/too-big-interval и его `info`, 403 user-blocked,
  404 и 500. Не придумывать лимит диапазона из примера.

## Вне scope

Автоматическое разбиение диапазона, paging, timezone conversion, WebSocket candles.
